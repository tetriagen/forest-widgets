# Monocraft

Bundled from the [official Monocraft repository](https://github.com/IdreesInc/Monocraft).

- Author: Idrees Hassan and contributors.
- File: `Monocraft.ttf` (Regular).
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
- Source: `dist/Monocraft-ttf/Monocraft.ttf` on the upstream `main` branch.

Monocraft is a fan-made typeface inspired by Minecraft, not an official Mojang font.
The installer adds it to the current user's fonts and does not change the system-wide font preference.
